# DishScan
## Installation 

### Supported Platforms 
This release supports Ubuntu 20.04 for DeepStream SDK 6.3 with Python 3.10. Other versions may require adjustments. The recommended setup is Docker-based for Jetson platforms, though a base environment can also be used.

### Installation
1. Pull the DeepStream Docker container
   Run the following command to download the official NVIDIA DeepStream container:
```bash
docker pull nvcr.io/nvidia/deepstream:6.3-triton-multiarch
'''
